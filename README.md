# Dr. Revanasiddappa Bandi — Academic Website

GitHub Pages package for the academic profile website.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `dr-revanasiddappa-bandi`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. After deployment, GitHub will provide the public website URL.

The homepage must be named `index.html` for GitHub Pages to serve it as the default page.
